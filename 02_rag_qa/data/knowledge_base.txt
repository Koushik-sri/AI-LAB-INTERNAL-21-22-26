=== Document: Company_AI_Policy.txt ===
Acme Corp AI Usage Guidelines and Data Privacy Policy:
1. All AI deployments must adhere to zero-retention data policies.
2. User PII (Personally Identifiable Information) must be sanitized before sending prompts to external LLM vendors.
3. Every automated customer-facing AI response must include a clear disclaimer stating "Generated by Acme AI Assistant".
4. High-risk transactions (financial refunds > $500, account terminations) require explicit human manager approval.

=== Document: System_Architecture.txt ===
Acme Core Platform System Architecture Specification:
1. The microservices architecture is deployed across AWS us-east-1 and us-west-2 with multi-region failover.
2. Primary relational storage uses PostgreSQL 15 with read-replicas for query scaling.
3. Vector similarity search uses Chroma vector databases for real-time RAG embeddings retrieval.
4. Message queuing between processing nodes uses Redis Pub/Sub with a Celery worker pool for background jobs.
